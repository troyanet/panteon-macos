# panteon-macos

Нативная утилита для macOS под клавиатуру **PANTEON T20 PRO** (контроллер Evision/Sinowealth, USB `320F:5080`).

Заводская клавиатура рассчитана на Windows и не имеет софта под macOS. Цель проекта:

1. **Адаптировать клавиши** под macOS (переназначение неудобных клавиш, напр. Home/End).
2. **Управлять RGB-подсветкой** (режимы, яркость, цвет) без Windows-утилиты.

## Статус

- [x] Идентификация устройства (`320F:5080`, Evision, служебный канал HID `0xFF00`).
- [x] Реверс протокола подсветки из родной Windows-утилиты (статически, без запуска).
- [ ] Swift-приложение: открытие HID, безопасный тест связи (query).
- [ ] Управление подсветкой.
- [ ] Переназначение клавиш.

## Протокол

Разобранный протокол устройства — в [`docs/protocol-notes.md`](docs/protocol-notes.md).
Кратко: команды — 64-байтные пакеты с контрольной суммой (opcode `4`, субкоманды
чтения/записи памяти устройства); покадровая подсветка — 17-байтные отчёты
(report `0xFF`). Потолок яркости канала — `0xF7`.

## ⚠️ Осторожно

Запись неверного протокола в клавиатуры на этом контроллере способна их
«окирпичить». Любая запись в устройство выполняется только после проверки
контрольной суммы и начинается с неразрушающих команд (query/read).

## Стек

Swift + нативный macOS UI, прямой доступ к устройству через IOKit HID.
